What this is

A Claude Code / Cowork plugin that turns a periodic 8-sheet QC export (refunds, ratings, sales, store mapping — across two regions) into a conversation: upload the file, ask a question or run a slash command, and get back a ranked table, a chart, or an exportable sheet, all built on one shared, locked scoring engine.

What's real vs. what's illustrative on this site: the scoring engine (scripts/cafe_qc_engine.py) and every number on these pages were computed using its exact formulas — composite scores, volume-tier handicaps, and the asymmetric sample floor are all genuinely calculated, not fudged. What's not real is the underlying data: 16 fabricated stores across two synthetic regions, with invented store names, refunds, ratings, and sales, built to exercise the engine's real code paths (alias fixes, an excluded location, a mapping collision, all three volume tiers). This site is a fixed snapshot with no upload button and no backend — to run this against a real export, use the plugin inside Claude Code/Cowork (see the repo README).

How it works

Every skill follows the same loop: locate the uploaded workbook, validate it against a locked data contract, elicit only what can't be inferred (region, timeframe, count), run the shared Python engine, then present the result in the format that command specifies. Full detail is in the repo's references/ docs.
