This site is the static companion to the live QC application. Both are based on the same deterministic synthetic 8-sheet workbook.

Want to actually upload a workbook? Use the live Streamlit app. Choose Use Sample Workbook there to run the exact synthetic data represented in this static preview.

What is real vs synthetic?

The store names, ratings, refunds, sales and mappings are fabricated. The identity resolution, volume handicap, QC scoring, SKU ranking and action-point logic are the real project logic. The corrected composite score combines refund badness + rating badness: lower means better quality; higher means greater QC risk.
